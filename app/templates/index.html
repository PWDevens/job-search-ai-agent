📋 Jobs CSV / XLSX Upload Guide

Your file must include at least title, company, and description columns. All other columns are optional but recommended for full pipeline tracking.

Column Required? Example value Notes
title ✅ YesSenior Data Engineer Job title exactly as posted
company ✅ YesAccenture Federal Services Employer name
description ✅ YesBuild pipelines using… Full job description text; drives matching
location ⬜ No Washington DC Used for geo filtering
salary ⬜ No 130000-165000 Range or single value; displayed only
url ⬜ No https://jobs.acme.com/… Direct link to job posting
date_posted ⬜ No 5/20/2026 When employer posted the role
date_found ⬜ No 5/31/2026 When you discovered the role
date_of_last_update⬜ No5/31/2026 Last time you updated this row
source ⬜ No LinkedIn · demo · Indeed Where you found the job
application_status⬜ NoApplied One of the statuses listed below ↓

Valid application_status values: Have Not Applied · Applied · Under Consideration · Interviewing · Offer Received · Rejected · Withdrawn

More effort = wider search + more options surfaced (slower). Not "more accurate" — quality comes from the matching, not raw compute.
